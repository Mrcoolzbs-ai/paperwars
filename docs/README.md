## Статус реализации на 22 ноября 2026 года

Документация Baseline v1.0 находится в Markdown; единая точка входа — [SPECIFICATION.md](SPECIFICATION.md). Правила и спецификация не равны готовности исполняемых игровых механик.

В main влиты этапы Stage 1.1–1.5 (PR #3–#7): monorepo/API skeleton, PostgreSQL/Drizzle, RNG/commit-reveal и хранение seed, аутентификация, доменные контракты и ruleset manifest.

**Draft PR #15** ([feat(web): add Paper Wars browser client MVP](https://github.com/Mrcoolzbs-ai/paperwars/pull/15)) находится в ветке `stage-3-browser-client`, основан на `stage-2-country-setup`, открыт и не влит. В нём добавлены seeded-карта с руслами рек, регистрация государства и культура, выход из кампании и лимит участников, библиотека религий/идеологий, карточки государства и выбранной системы, символы построек и их отображение на большой карте. Игровые действия после основания пока отключены до появления движка ходов.

Последняя завершённая успешная CI-сборка до восстановления спецификации выполнена для кода PR #15 на коммите `2ca23d1f2c14c19c4180b2563277e6afe3d77117`: Build, Typecheck, Lint, Format check, 68/68 тестов в 14 файлах. После восстановления спецификации и обновления BAT-обновлятора CI повторно запускается для текущей ветки; актуальное состояние проверок доступно на [странице GitHub Actions для stage-3-browser-client](https://github.com/Mrcoolzbs-ai/paperwars/actions?query=branch%3Astage-3-browser-client). [Предыдущий успешный прогон](https://github.com/Mrcoolzbs-ai/paperwars/actions/runs/45065489740).

Ограничения текущего MVP:
- Полный Simulation Engine, разрешение ходов и worker ещё не подключены.
- После основания государства пока нельзя строить, перемещать столицу, колонизировать или отдавать игровые приказы.
- Не завершены колонизация, снос, добыча золота, экономика, производство, армия, дипломатия и полный игровой цикл.
- Численные эффекты культуры и принципов не применяются движком; часть показателей карточек пока является визуальными заглушками.
- Генератор мира пока не моделирует высоты, биомы, климат, озёра и полноценную гидрологию.

**Важно о соответствии Baseline:** нормативные правила требуют административного согласования религии/идеологии до её официального назначения. Текущий PR #15 временно делает новые системы автоматически доступными и убирает вкладку модерации из обычной навигации. Это расхождение реализации с Baseline, а не молчаливое изменение правила.

Q18–Q20 остаются PROPOSAL и не входят в канон.
