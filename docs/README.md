## Статус

Этот каталог находится в процессе восстановления. Восстановленная спецификация и дорожная карта обновлены по первым двум частям переданных материалов, включая технический аудит RNG, seed storage, Worker fencing/lease, фаз хода, DiscoveryAccess и финальные решения Q7–Q10, Q15–Q17, Q21–Q24. Это рабочие документы, а не полная дословная транскрипция исходных DOCX и не завершённый комплект нормативных файлов Baseline v1.0.

По мере получения следующих частей материалов документы будут уточняться. Исторические редакции, предложения разработчика и последние решения автора должны оставаться различимыми.

До полной сверки первичных материалов не заполнять отсутствующие правила догадками и не реализовывать неподтверждённые игровые механики.

## План восстановления полного Baseline

1. Извлечь и структурировать содержимое обоих DOCX.
2. Восстановить `rules/legacy-rules.md`, `rules/new-rules.md`, `rules/open-questions.md`, `rules/rule-provenance.md`.
3. Восстановить `lore/canon.md` и `lore/unconfirmed-proposals.md`.
4. Восстановить архитектурные спецификации overview, randomness, turn processing, discovery и information visibility.
5. Сверить все документы и только затем пометить полный комплект как Documentation Baseline v1.0.
