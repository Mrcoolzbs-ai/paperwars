## Статус

Этот каталог находится в процессе восстановления. Файл `RECOVERED_SPECIFICATION.md` — рабочая реконструкция по подтверждённым решениям проектной переписки, а не полная дословная транскрипция исходных DOCX и не завершённый комплект нормативных файлов Baseline v1.0.

До полной сверки первичных материалов не заполнять отсутствующие правила догадками и не реализовывать неподтверждённые игровые механики.

## План восстановления полного Baseline

1. Извлечь и структурировать содержимое обоих DOCX.
2. Восстановить `rules/new-rules.md`, `rules/open-questions.md`, `rules/rule-provenance.md`, `rules/legacy-rules.md`.
3. Восстановить архитектурные спецификации randomness, turn processing, discovery и information visibility.
4. Сверить все документы и только затем пометить полный комплект как Documentation Baseline v1.0.
