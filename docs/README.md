# Documentation status

`Documentation Baseline v1.0` был согласован как нормативная спецификация в ходе проектной работы, однако полный комплект его Markdown-файлов на момент создания этого файла не был загружен в данный GitHub-репозиторий.

Два DOCX-файла, уже находящиеся в корне репозитория, сохранены как исходные материалы. Они не считаются заменой полного набора `new-rules.md`, `open-questions.md`, `rule-provenance.md` и архитектурных документов.

**Ограничение:** до переноса и сверки полного Baseline v1.0 разрешены только нейтральная инфраструктура и технические контракты. Не реализовывать игровые механики, значения баланса, фазы хода, боевые правила, RNG или структуру игровых сохранений на основании неполных выдержек.
