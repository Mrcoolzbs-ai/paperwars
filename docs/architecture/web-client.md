# Графический Web-клиент

## Назначение

`apps/web` — браузерный клиент предварительной версии Paper Wars: Rebirth. Это отдельное workspace-приложение без стороннего UI-фреймворка: статическая страница собирается встроенными средствами Node.js 22 и раздаётся тем же Fastify API на `/`.

Клиент не заменяет серверную валидацию. Все сохранения проходят через API и доменные сервисы.

## Текущие экраны

- Карта мира: seeded-карта с руслами рек, резервированием стартовой территории и отображением государств. Значки построек на большой карте рисуются отдельным проходом после подписей стран, поэтому не перекрываются названиями. На малом масштабе показываются компактные маркеры; золотая шахта обозначается кириллической буквой «З».
- Редактор страны: сетка 5×5, выбор клетки и размещение семи стартовых зданий. Сервер проверяет состав зданий, сушу, население и координаты.
- Учётная запись: регистрация, вход, access token и обновление сессии через HttpOnly refresh cookie.
- Кампании: список кампаний, создание, подключение и выход; показывается заполнение слотов участников.
- Религии и идеологии: личная библиотека учений, загрузка в редактор, изменение и повторное сохранение либо добавление без изменений в текущую кампанию.
- После основания страны вкладки превращаются в карточки страны и её официальной веры/идеологии. Карточки оформлены как бумажные досье с табличными секциями; показатели, которых симуляция пока не рассчитывает, отмечены как недоступные.
- Культура в карточке страны показывается набором SVG-символов. Наведение мыши и клавиатурный фокус открывают подсказку с названием и описательным эффектом. Неподтверждённые числовые модификаторы не придумываются.
- После основания страны игровые действия временно отключены. Строительство, перенос столицы, колонизация, заказы и другие команды станут доступны после реализации Simulation Engine и turn processing. Соответствующие HTTP-маршруты строительства и переноса столицы пока не публикуются.

Ручная модерация социальных систем не входит в текущий автоматический flow клиента. Это расхождение с нормативным Baseline отдельно описано в [SPECIFICATION.md](../SPECIFICATION.md); до решения автора оно не отменяет правило Baseline.

## Сборка и запуск

Из корня репозитория:

```bash
corepack pnpm install
cp .env.example .env
docker compose up -d db
corepack pnpm db:migrate
corepack pnpm build
corepack pnpm dev:api
```

Откройте `http://127.0.0.1:3000`. Для запуска собранного API используется `corepack pnpm start:api`.

Скрипт `apps/web/scripts/build.mjs` очищает `apps/web/dist` и копирует туда статический клиент. Корневой `pnpm build` включает этот пакет. API раздаёт `apps/web/dist/index.html` по корневому URL; если клиент не собран, API возвращает HTTP 503 с сообщением о необходимости выполнить build.

## Архивная визуальная основа

Схематическая сеточная карта, русла рек, проливы, акцент на клеточной географии и стартовая область 5×5 основаны на визуальных материалах из загруженных архивов сообщества:

- VK discussions export от 21 ноября 2026 года: исходное описание территории государства 5×5 и изображения с маркером столицы.
- VK wall export от 21 ноября 2026 года: исторические изображения общей карты мира, клеточной сетки и водных рубежей.

Текущая карта — интерфейсная схема и координатная поверхность для раннего этапа регистрации. Это не точная геопривязанная копия архивной карты и не полноценный генератор/редактор мира.

## Границы реализации

- Клиент отображает карту и отправляет координаты/размещения в country setup API; полноценные world DTO и загрузка сохранённого состояния карты ещё не реализованы.
- Разделы приказов, армии и дипломатии пока являются навигационными заглушками.
- Полный turn resolver, обработка приказов, worker, закрытие и финализация хода не реализованы.
- Доступ к чужим социальным системам требует ruleset-политики географической доступности. Клиент не придумывает радиус и не позволяет обойти серверную политику.
- Реальное взаимодействие требует PostgreSQL, настроенного `.env` и применения миграций.


## Первые действия страны (MVP)

- На вкладке государства показана интерактивная собственная территория 5×5.
- Строительство дополнительной фабрики, поля, лаборатории, церкви, казармы или башни размещает объект на свободной сухопутной клетке, занимающей одного жителя. Сервер блокирует занятые клетки, воду и клетки без жителя.
- Перенос столицы перемещает её на другую свободную сухопутную клетку и освобождает прежнюю.
- Изменения сохраняются в `country_buildings`, `country_cells`, `game_events` и обновлённом snapshot первого хода; большая карта получает новые типы построек из API.
- Это ограниченный стартовый набор: действие пока выполняется сразу, без очков действий и завершения хода. Колонизация, снос, добыча/расход ресурсов, армии, дипломатия и полный движок ОД ещё не подключены.
- Карточки государства и официальной веры/идеологии следуют макетам из архивного DOCX. Культура показывается символами; всплывающие подсказки поясняют общественный смысл выбранной позиции. Эти пояснения пока описательные, не рассчитанные игровые модификаторы.
