# Чаты Paper Wars

## Каналы

### Мировой чат
- Общая комната всех активных авторизованных пользователей Paper Wars.
- Доступен из встроенного всплывающего окна игры по кнопке «Чаты» и из отдельной страницы `/chat`; мировой канал не требует участия в кампании.
- В БД сообщения имеют `scope = 'world'` и `campaign_id IS NULL`.

### Чат кампании
- Отдельная комната каждой кампании; во встроенном окне все комнаты доступны списком. Сначала показывается мировой чат, ниже — кампании с активным членством текущего игрока.
- Читать и отправлять сообщения могут только пользователи с активной записью `campaign_memberships` для данной кампании.
- Проверка членства выполняется сервером на каждом чтении и отправке. Строка membership блокируется `FOR SHARE` на всё время операции.
- Сообщения имеют `scope = 'campaign'` и обязательный FK на кампанию. Удаление кампании каскадно удаляет её сообщения.

## HTTP API

- `GET /chat` — автономная HTML-страница чатов.
- `GET /chat/world` — последние 50 мировых сообщений.
- `POST /chat/world` — отправить мировое сообщение, JSON `{ "message": "..." }`.
- `GET /campaigns/:campaignId/chat` — последние 50 сообщений комнаты кампании.
- `POST /campaigns/:campaignId/chat` — отправить сообщение в комнату кампании.

Все четыре API endpoint требуют Bearer access token. Страница `/chat` публична, но сообщения не загружаются до авторизации.

DTO сообщения содержит id, scope, campaignId, безопасную метку автора вида `Игрок A1B2C3`, текст, время создания и `isMine`. Email и внутренние идентификаторы пользователя не возвращаются.

## Ограничения и клиент
- Основной игровой клиент открывает отдельное модальное окно по кнопке «Чаты» в верхней панели. Слева расположен список комнат: мировой канал всегда первый, затем все кампании с активным членством; справа — история и поле отправки.
- Встроенное окно закрывается кнопкой, кликом по затемнённому фону или клавишей Escape. На узких экранах список комнат превращается в горизонтальную полосу.
- При открытии окна список кампаний загружается через `GET /campaigns`; этот endpoint возвращает только кампании, где у пользователя активное членство.
- Встроенный клиент обновляет историю активной комнаты каждые 5 секунд только пока окно открыто и вкладка видима.
- Текст обрезается по внешним пробелам; пустые строки отклоняются. Максимум — 2000 символов.
- Общее для обоих каналов ограничение: 5 сообщений на пользователя за скользящие 10 секунд. Параллельные отправки сериализуются advisory lock в PostgreSQL.
- История ограничена последними 50 сообщениями; курсорной пагинации пока нет.
- Клиент обновляет активную комнату каждые 5 секунд, пока вкладка видима. Идентификаторы запросов защищают от отображения запоздавших ответов предыдущего канала.
- Enter отправляет, Shift+Enter добавляет строку. Содержимое отображается как текст и не интерпретируется как HTML.
- Refresh token хранится только в HttpOnly cookie; access token остаётся в памяти страницы.
- Вложения, реакции, редактирование/удаление сообщений, старшая история и инструменты модерации не входят в текущий этап.
