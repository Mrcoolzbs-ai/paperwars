# Чаты Paper Wars

## Каналы

### Мировой чат
- Общая комната всех вошедших и активных аккаунтов Paper Wars.
- Доступна из списка кампаний, даже если пользователь пока не состоит ни в одной кампании.
- Сообщения хранятся с \`scope = 'world'\` и \`campaign_id IS NULL\`.

### Чат кампании
- Отдельная комната выбранной кампании.
- Читать и отправлять сообщения могут только пользователи с активной записью \`campaign_memberships\` для этой кампании.
- Проверка членства выполняется сервером на каждом чтении и отправке. Во время операции строка membership удерживается через \`FOR SHARE\`, чтобы конкурентное исключение/отзыв членства не пересеклось с записью.
- Сообщения сохраняются с \`scope = 'campaign'\` и обязательным FK на текущую кампанию. Удаление кампании каскадно удаляет её сообщения.

## HTTP API

- \`GET /chat/world\` — последние 50 мировых сообщений.
- \`POST /chat/world\` — отправить мировое сообщение, JSON-тело \`{ "message": "..." }\`.
- \`GET /campaigns/:campaignId/chat\` — последние 50 сообщений комнаты кампании (только active member).
- \`POST /campaigns/:campaignId/chat\` — отправить сообщение в комнату кампании.

DTO сообщения включает id, scope, campaignId, безопасную игровую метку автора вида \`Игрок A1B2C3\`, текст, время создания и \`isMine\`. Email и внутренний user UUID в чат DTO не попадают.

## Ограничения и клиент

- Текст обрезается по внешним пробелам; пустые строки отклоняются. Максимальная длина — 2000 символов.
- Ограничение частоты: не более 5 сообщений на пользователя за 10 секунд, общее для обоих каналов. Превышение возвращает HTTP 429.
- История ограничивается последними 50 сообщениями; сейчас cursor/постраничной загрузки более старой истории нет.
- Web-клиент обновляет выбранную комнату polling-запросом каждые 5 секунд, когда экран чата активен. Отдельные request IDs не дают запоздавшему ответу предыдущей комнаты заменить текущий канал.
- Отправка — Enter, новая строка — Shift+Enter. HTML не интерпретируется: сервер сохраняет plain text, клиент экранирует содержимое перед рендерингом.
- Вложения, реакции, редактирование/удаление сообщений и пользовательская модерация не входят в этот increment.
