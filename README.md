# Paper Wars: Rebirth

Технический каркас браузерной военно-политической стратегии. Игровые механики на Stage 1.1 не реализованы.

## Текущий статус

**Stage 1.1 — monorepo bootstrap.** Создаются границы пакетов, API health-check, базовые типы и smoke-тесты. PostgreSQL, миграции, RNG и игровые правила будут добавляться отдельными задачами.

## Документация и исходные материалы

Два исходных DOCX-файла, загруженных в репозиторий, сохранены без изменений. Полный комплект утверждённых Markdown-документов **Documentation Baseline v1.0 пока не находится в этом репозитории**. До его переноса игровые механики в код не добавлять. См. [`docs/README.md`](docs/README.md).

## Структура

- `apps/api` — HTTP API и точка запуска сервера.
- `packages/shared` — общие типы, идентификаторы, координаты и ошибки.
- `packages/domain` — платформенно-независимые доменные контракты.
- `packages/simulation` — публичная оболочка Simulation Engine; разрешение хода пока не реализовано.
- `packages/persistence` — интерфейсы портов хранения, без конкретной БД.
- `tests` — интеграционные smoke-тесты.
- `docs` — документация и статус переноса baseline.

## Требования

- Node.js 22 или совместимый поддерживаемый LTS-релиз.
- pnpm 9.15.0 или новее в рамках pnpm 9.

## Установка и проверки

```bash
corepack pnpm install
corepack pnpm format
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm test
corepack pnpm build
```

## Запуск API

```bash
corepack pnpm dev:api
```

Health-check: `GET http://127.0.0.1:3000/health`.

## Важные ограничения Stage 1.1

- Нет игровых алгоритмов и фиктивных результатов симуляции.
- Доменный слой не зависит от HTTP или persistence.
- Simulation Engine не читает системное время и не использует глобальный RNG.
- API-модуль можно импортировать в тестах без запуска HTTP-сервера.
- Реальная БД, схема, миграции и сохранения относятся к следующим задачам.
